# 청년 혜택 알리미

내 조건에 맞는 수도권 청년 혜택(주거 · 금융·자산 · 고용·소득 · 세제)만 골라 마감 순서대로 보여주는 모바일 웹앱이에요.

- 로그인 없이 브라우저에 프로필과 저장한 정책을 보관해요.
- 정책·자격 조건·정책 간 관계·기준값은 구글 시트에서 바로 읽어요. 시트를 고치면 1분 안에 반영돼요.
- 판정 결과는 참고용이에요. 실제 자격은 신청 기관 심사로 확정돼요.

## 데이터

| 시트 탭 | 쓰는 곳 |
|---|---|
| 정책 | 목록·상세·저장함 일정 (`화면용 샘플 마감일`, `화면용 접수 시작일`), `지역 기준`(거주지 / 희망 지역) |
| 임대주택 공고 | 희망 지역 정책의 단지별 공고 (정책 ID, 시도, 시군구, 접수 시작·마감, 링크). 희망 지역에 아직 마감되지 않은 단지가 있어야 정책이 보여요 |
| 상품 비교 | 기관별 기본·최고 금리와 우대 조건(급여이체·카드실적·첫거래·주거래·자동이체·비대면) 3개. 행이 있는 정책은 상세에 '최적 선택지 찾기'가 생겨요 |
| 자격 조건 | 자격 판정. N~Y열이 계산용 칸 |
| 정책 간 관계 | 상세 화면의 "다른 정책과 비교" |
| 기준값 | 기준 중위소득, 도시근로자 월평균소득, 건강보험료율, 판정 기준일 |

- 배포 환경에서는 `api/sheet.js`가 시트를 CSV로 가져와요. 시트는 "링크가 있는 모든 사용자 보기"여야 해요.
- 시트를 읽지 못하면 `public/data/*.csv`에 저장해 둔 데이터를 써요.

### 계산용 칸 (자격 조건 N~Y)

| 칸 | 값 |
|---|---|
| 재직 코드 | 무관 / 재직 / 구직 |
| 기업 규모 코드 | 무관 / 중소 / 중소·중견 |
| 청약통장 필수 | Y / N |
| 본인 소득 기준 | 없음 / 중위소득% / 도시근로자% / 월 원 / 연 만원 (본인 1인 가구 기준) |
| 본인 소득 상한·하한 | 기준 단위의 숫자 |
| 부모 소득 기준 | 없음 / 중위소득% / 도시근로자% (원가구 = 부모 추정 소득 + 본인) / 연 만원 (부모 소득만) |
| 부모 소득 상한 | 숫자 |
| 부모 소득 성격 | 필수 (넘으면 제외) / 우선순위 (넘어도 3순위로 신청 가능) |
| 취약 코드 | 없음 / 우선순위 / 우대 / 필수 / 제외 / 확인 필요 |
| 취약 대상 | 쉼표로 구분한 항목 (온보딩 마지막 문항과 같은 이름) |
| 판정 메모 | 판정하지 않은 조건 안내 |

부모 소득은 건강보험료로 추정해요. 직장가입자는 `월 보험료 ÷ 본인부담률`, 지역가입자는 `월 보험료 ÷ 보험료율`로 계산해요. 한 분이라도 '모름'이면 충족으로 가정하고 "부모 소득 확인 필요"를 표시해요.

## 개발

```bash
npm install
npm run dev     # 로컬에서는 /api가 없어서 저장된 CSV로 동작해요
npm run build
```

## 최적 선택지 비교 (선택)

`api/explain.js`는 Vercel 환경변수 `ANTHROPIC_API_KEY`가 있을 때만 비교 결과를 두 문장으로 정리해요. 키가 없으면 정리 칸 없이 계산 결과만 보여줘요.

- `EXPLAIN_MODEL` (기본 `claude-sonnet-5-5`), `EXPLAIN_DAILY_LIMIT` (기본 300회/일, 서버 인스턴스 기준)
